# Everyday care for automatic OKEY and Mahjong tables

[English](en.md) | [简体中文](zh.md) | [Türkçe](tr.md) | [Deutsch](de.md)

A short owner checklist for external care. Follow the exact table and tile manuals for cleaning products, access, movement and service intervals. The same fault code can mean different things on different models.

## Before each session

- Check that the floor is stable, the table is level and any required locks are secured.
- Keep drinks and small objects away from openings; keep ventilation clear.
- Check the visible cord and plug for damage without opening electrical parts. Confirm the nameplate matches the supply configuration.
- Use the complete, compatible, clean and dry tile set for the selected mode. Keep spare, chipped, swollen or mixed tiles out.

## After each session

1. Stop using the table, switch it off and unplug before cleaning.
2. Remove loose objects from the exterior. Wipe accessible outer surfaces with a soft cloth using only the method permitted by the manufacturer.
3. Use approved tile-cleaning methods; dry tiles completely before loading. Never spray liquid into openings or soak the table.
4. Inspect the surface and tiles for damage, then store in a dry place. Follow the model's procedure when folding or moving; arrange suitable lifting help.

No generic lubrication or internal-cleaning schedule applies to every table. Keep internal mechanisms, electrical work and uncertain access for qualified service. A quick-release panel does not make every internal task a user task.

## When something changes

| Symptom | Owner action | Next step |
|---|---|---|
| Missing or unexpected tiles | Record selected mode and count visible tiles after safe shutdown | Compare the exact mode's instructions; do not reach inside to find the balance |
| Jam, grinding or repeated stop | Stop the cycle and disconnect power when safe | Do not force mechanisms or run repeated test cycles; contact service |
| Fault code | Record full text, flashing position and what was happening | Use the exact model reference; do not borrow another brand's code meaning |
| Smoke, burning smell, liquid ingress, shock or damaged electrical parts | Stop use; disconnect only if it can be done safely | Keep out of use and obtain qualified service |

A restart is appropriate only if the model procedure permits it and there are no danger signs. If the fault returns, stop. Do not recreate a dangerous event for a video.

## Private service report

Send support: model, country, nameplate rating, selected mode, approved tile count, exact symptom/code, affected side, first occurrence, recent move/cleaning/spill, checks already made, and safe photos. Send order and serial details privately. Public correction reports should omit personal/customer details.
